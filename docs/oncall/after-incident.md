# After an Incident

Use this guide once Engineering has declared the incident resolved.

## Close out


| Engineering                                                                                                                                                                                                                                                                                                                                                                                                                        | Support                                                                                                                                                                                                                                                                                                                                                                                           |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| - Mark any open status-page notice resolved.<br>- If releases were frozen, lift the freeze when safe ([Release Freeze](https://github.com/OpenRouterTeam/openrouter-web/actions/workflows/release-freeze.yaml) with `is_frozen` unchecked). If it must stay, record the owner, reason, and next review time in the incident.<br>- Track cleanup of temporary mitigations in Linear with owners, even if no postmortem is required. | - Send the final customer update with confirmed recovery and any remaining limitations.<br>- Close the Pylon ticket after the customer confirms recovery, or after four hours without a reply to the confirmation request. Record silence as “no customer confirmation,” not confirmed recovery.<br>- If the customer reports continuing impact, keep the ticket open and report it in the incident channel. For SEV-1/SEV-2 or unclear impact, return to [triage](./first-15-minutes.md) and [page Engineering](./first-15-minutes.md#page-the-other-rotation) if not already engaged. |


## Postmortem — within five business days


| Engineering                                                                                                                                                                                                                                                                                                                                                                                                                                      | Support                                                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| - Check [Priority and Severity](./severity.md) for whether a postmortem is required.<br>- If required, name an author and write a blameless postmortem using the [postmortem drafting guide](../../.agents/skills/create-post-mortem/SKILL.md). Cover impact, timeline, contributing causes, and recovery.<br>- Record concrete action items in Linear with owners.<br>- **SEV-1:** the incident commander approves the customer-facing version. | - **SEV-1:** share the approved postmortem with the customer. |
