# Priority and Severity

> One severity scale, three inputs. **Pylon ticket priority**, **Datadog monitor priority**, and **Datadog incident** severity all map onto it.

Tickets alone do not page, regardless of priority. See [Paging](./paging.md) for triggers and routing.
