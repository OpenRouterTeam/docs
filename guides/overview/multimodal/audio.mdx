OpenRouter supports audio through dedicated speech endpoints and through multimodal chat models. Choose the API that matches your use case:

- **Dedicated Speech-to-Text (`POST /api/v1/audio/transcriptions`)**: Transcribe audio files with Whisper, GPT-4o Transcribe, Deepgram, ElevenLabs Scribe, and other STT models. See the [Speech-to-Text guide](/guides/overview/multimodal/stt) and discover STT models with `GET /api/v1/models?output_modalities=transcription`.
- **Dedicated Text-to-Speech (`POST /api/v1/audio/speech`)**: Generate speech audio (`mp3` or `pcm`) from text with OpenAI, Gemini, ElevenLabs, Fish Audio, Voxtral, and other TTS models. See the [Text-to-Speech guide](/guides/overview/multimodal/tts) and discover TTS models and voices with `GET /api/v1/audio/speech/models`.
- **Multimodal chat models (this page)**: Send audio alongside text prompts for analysis, Q&A, or reasoning, or receive conversational audio responses from audio-capable chat models.

## Audio Inputs

Send audio files to multimodal chat models for analysis, Q&A, and processing alongside text prompts. For dedicated speech-to-text transcription (including multipart file uploads, inline audio, direct URLs on models that support them, and silence handling without LLM hallucination), use the [Speech-to-Text endpoint](/guides/overview/multimodal/stt) (`POST /api/v1/audio/transcriptions`) instead.

Multimodal audio input requests use the [Responses API](/api_reference/responses/overview) (`/api/v1/responses`) with the `input_audio` content type. Audio files must be base64-encoded and include the format specification.

**Note**: Audio files must be **base64-encoded** - direct URLs are not supported for audio content.

You can search for models that support audio input by filtering to audio input modality on our [Models page](/guides/overview/models).

### Sending Audio Files

Here's how to send an audio file for processing:

<CodeGroup>

```typescript title="TypeScript SDK" expandable lines
import { OpenRouter } from '@openrouter/sdk';
import fs from "fs/promises";

const openRouter = new OpenRouter({
  apiKey: '<OPENROUTER_API_KEY>',
});

async function encodeAudioToBase64(audioPath: string): Promise<string> {
  const audioBuffer = await fs.readFile(audioPath);
  return audioBuffer.toString("base64");
}

// Read and encode the audio file
const audioPath = "path/to/your/audio.wav";
const base64Audio = await encodeAudioToBase64(audioPath);

const result = await openRouter.responses.send({
  responsesRequest: {
    model: "google/gemini-2.5-flash",
    input: [
      {
        role: "user",
        content: [
          {
            type: "input_text",
            text: "Please transcribe this audio file.",
          },
          {
            type: "input_audio",
            inputAudio: {
              data: base64Audio,
              format: "wav",
            },
          },
        ],
      },
    ],
    stream: false,
  },
});

console.log(result);
```

### Supported Audio Input Formats

The Responses API (`/api/v1/responses`) accepts two `format` values for `input_audio`:

- `wav` - WAV audio
- `mp3` - MP3 audio

Chat Completions (`/api/v1/chat/completions`) accepts any format string the provider supports, such as `aiff`, `aac`, `ogg`, `flac`, `m4a`, `pcm16`, or `pcm24`, in the `input_audio.format` field of its content parts.

**Note:** Check your model's documentation to confirm which audio formats it supports. Not all models support all formats.

## Audio Output

OpenRouter supports receiving conversational audio responses from chat models that have audio output capabilities. For dedicated text-to-speech synthesis from text with `mp3` or `pcm` output, use the [Text-to-Speech endpoint](/guides/overview/multimodal/tts) (`POST /api/v1/audio/speech`) instead. To request audio output from a chat model, include the `modalities` and `audio` parameters in your request. Audio output uses the Chat Completions API (`/api/v1/chat/completions`), because the Responses API does not accept the `audio` parameter.

You can search for models that support audio output by filtering to audio output modality on our [Models page](/guides/overview/models).

### Requesting Audio Output

To receive audio output, set `modalities` to `["text", "audio"]` and provide the `audio` configuration with your desired voice and format:

<CodeGroup>

```python Python expandable lines
import os
import requests
import json
import base64

url = "https://openrouter.ai/api/v1/chat/completions"
headers = {
    "Authorization": f"Bearer {os.environ['OPENROUTER_API_KEY']}",
    "Content-Type": "application/json"
}

payload = {
    "model": "openai/gpt-audio",
    "messages": [
        {
            "role": "user",
            "content": "Say hello in a friendly tone."
        }
    ],
    "modalities": ["text", "audio"],
    "audio": {
        "voice": "alloy",
        "format": "pcm16"
    },
    "stream": True
}

# Audio output requires streaming — the response is delivered as SSE chunks
response = requests.post(url, headers=headers, json=payload, stream=True)
if not response.ok:
    raise RuntimeError(f"Request failed: {response.status_code} {response.text}")

# SSE is UTF-8. Set it explicitly so a response without a charset is not decoded as ISO-8859-1
response.encoding = "utf-8"

audio_data_chunks = []
transcript_chunks = []

for line in response.iter_lines(decode_unicode=True):
    if not line or not line.startswith("data: "):
        continue
    data = line[len("data: "):]
    if data.strip() == "[DONE]":
        break
    chunk = json.loads(data)
    choices = chunk.get("choices") or []
    if not choices:
        continue
    delta = choices[0].get("delta") or {}
    audio = delta.get("audio") or {}
    if audio.get("data"):
        audio_data_chunks.append(audio["data"])
    if audio.get("transcript"):
        transcript_chunks.append(audio["transcript"])

transcript = "".join(transcript_chunks)
print(f"Transcript: {transcript}")

# Combine and decode the base64 audio chunks (raw PCM16), then save
full_audio_b64 = "".join(audio_data_chunks)
audio_bytes = base64.b64decode(full_audio_b64)
with open("output.pcm", "wb") as f:
    f.write(audio_bytes)
print(f"Saved {len(audio_bytes)} bytes of PCM16 audio to output.pcm")

```

```typescript title="TypeScript (fetch)" expandable lines
const response = await fetch("https://openrouter.ai/api/v1/chat/completions", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.OPENROUTER_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "openai/gpt-audio",
    messages: [
      {
        role: "user",
        content: "Say hello in a friendly tone.",
      },
    ],
    modalities: ["text", "audio"],
    audio: {
      voice: "alloy",
      format: "pcm16",
    },
    stream: true,
  }),
});

if (!response.ok) {
  throw new Error(`Request failed: ${response.status} ${await response.text()}`);
}

// Audio output requires streaming — parse the SSE chunks
const reader = response.body!.getReader();
const decoder = new TextDecoder();

const audioDataChunks: string[] = [];
const transcriptChunks: string[] = [];
let buffer = "";

stream: while (true) {
  const { done, value } = await reader.read();
  if (done) break;

  buffer += decoder.decode(value, { stream: true });
  const lines = buffer.split("\n");
  buffer = lines.pop()!; // keep incomplete line in buffer

  for (const line of lines) {
    if (!line.startsWith("data: ")) continue;
    const data = line.slice("data: ".length).trim();
    if (data === "[DONE]") break stream;

    const chunk = JSON.parse(data);
    const audio = chunk.choices?.[0]?.delta?.audio;
    if (audio?.data) audioDataChunks.push(audio.data);
    if (audio?.transcript) transcriptChunks.push(audio.transcript);
  }
}

const transcript = transcriptChunks.join("");
console.log(`Transcript: ${transcript}`);

// audioDataChunks joined together is the full base64-encoded audio (raw PCM16)
const fullAudioB64 = audioDataChunks.join("");
console.log(`Received ${fullAudioB64.length} base64 characters of audio`);

```

```go title="Go" lines
package main

import (
	"bufio"
	"bytes"
	"encoding/json"
	"fmt"
	"io"
	"log"
	"net/http"
	"os"
	"strings"
)

func main() {
	body, _ := json.Marshal(map[string]any{
		"model": "openai/gpt-audio",
		"messages": []any{
			map[string]any{"role": "user", "content": "Say hello in a friendly tone."},
		},
		"modalities": []string{"text", "audio"},
		"audio":      map[string]any{"voice": "alloy", "format": "pcm16"},
		"stream":     true,
	})

	req, _ := http.NewRequest("POST", "https://openrouter.ai/api/v1/chat/completions", bytes.NewReader(body))
	req.Header.Set("Authorization", "Bearer "+os.Getenv("OPENROUTER_API_KEY"))
	req.Header.Set("Content-Type", "application/json")

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		log.Fatal(err)
	}
	defer resp.Body.Close()
	if resp.StatusCode != http.StatusOK {
		msg, _ := io.ReadAll(resp.Body)
		log.Fatalf("Request failed: %d %s", resp.StatusCode, msg)
	}

	// Audio output requires streaming — parse the SSE chunks
	var audioData, transcript strings.Builder
	scanner := bufio.NewScanner(resp.Body)
	scanner.Buffer(make([]byte, 1024*1024), 16*1024*1024)
	for scanner.Scan() {
		line := scanner.Text()
		if !strings.HasPrefix(line, "data: ") {
			continue
		}
		data := strings.TrimSpace(strings.TrimPrefix(line, "data: "))
		if data == "[DONE]" {
			break
		}

		var chunk struct {
			Choices []struct {
				Delta struct {
					Audio struct {
						Data       string `json:"data"`
						Transcript string `json:"transcript"`
					} `json:"audio"`
				} `json:"delta"`
			} `json:"choices"`
		}
		if err := json.Unmarshal([]byte(data), &chunk); err != nil || len(chunk.Choices) == 0 {
			continue
		}
		audio := chunk.Choices[0].Delta.Audio
		audioData.WriteString(audio.Data)
		transcript.WriteString(audio.Transcript)
	}
	if err := scanner.Err(); err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Transcript: %s\n", transcript.String())

	// audioData is the full base64-encoded audio (raw PCM16)
	fmt.Printf("Received %d base64 characters of audio\n", audioData.Len())
}
```

### Streaming Chunk Format

Audio output requires streaming (`stream: true`). Audio data and transcript are delivered incrementally via the `delta.audio` field in each chunk:

```json lines
{
  "choices": [
    {
      "delta": {
        "audio": {
          "data": "<base64-encoded audio chunk>",
          "transcript": "Hello"
        }
      }
    }
  ]
}
```

### Audio Configuration Options

The `audio` parameter accepts the following options:

| Option | Description |
|---|---|
| `voice` | The voice to use for audio generation (e.g., `alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`). Available voices vary by model. |
| `format` | Must be `pcm16` when streaming (`stream: true` is required for chat-completions audio output). Requesting `mp3`, `wav`, `flac`, or `opus` on a streaming chat-completions request is rejected by upstream providers; use the dedicated [Text-to-Speech endpoint](/guides/overview/multimodal/tts) (`POST /api/v1/audio/speech`) for `mp3` output (it supports `mp3` and `pcm`). |
