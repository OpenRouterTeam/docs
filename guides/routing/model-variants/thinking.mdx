<Warning>
**Deprecated**

The `:thinking` variant is deprecated and is being removed. Use the [`reasoning` parameter](/guides/best-practices/reasoning-tokens) instead, which works across models and lets you control the reasoning budget per request.
</Warning>

The `:thinking` variant enabled reasoning by default on models that shipped a dedicated reasoning endpoint. Reasoning is now requested per call through the `reasoning` parameter, so no new models will carry this suffix.

See also: [Reasoning Tokens](/guides/best-practices/reasoning-tokens)
