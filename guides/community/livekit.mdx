## Using LiveKit Agents

[LiveKit Agents](https://docs.livekit.io/agents/) is an open-source framework for building voice AI agents. The OpenRouter plugin allows you to access 400+ AI models from multiple providers through a unified API, with automatic fallback support and intelligent routing.

### Installation

Install the OpenAI plugin to add OpenRouter support:

```bash lines
uv add "livekit-agents[openai]~=1.2"
```

### Authentication

The OpenRouter plugin requires an [OpenRouter API key](https://openrouter.ai/settings/keys). Set `OPENROUTER_API_KEY` in your `.env` file.

### Basic Usage

Create an OpenRouter LLM using the `with_openrouter` method:

<CodeGroup>

```python title="Python" lines
from livekit.agents import AgentSession
from livekit.plugins import openai

session = AgentSession(
    llm=openai.LLM.with_openrouter(model="anthropic/claude-sonnet-4.5"),
    # ... tts, stt, vad, turn_detection, etc.
)
```

</CodeGroup>

### Advanced Features

#### Fallback Models

Configure multiple fallback models to use if the primary model is unavailable:

<CodeGroup>

```python title="Python" lines
# The LiveKit plugin can't run here, so call OpenRouter directly with the same fallback configuration
import os

from openrouter import OpenRouter

with OpenRouter(api_key=os.environ["OPENROUTER_API_KEY"]) as client:
    res = client.chat.send(
        model="openai/gpt-4o",
        # Fallback models are tried in order if the primary model is unavailable
        models=[
            "openai/gpt-4o",
            "anthropic/claude-sonnet-4.5",
            "openai/gpt-5-mini",
        ],
        messages=[{"role": "user", "content": "Say hello in one short sentence."}],
    )

    print("Model that answered:", res.model)
    print(res.choices[0].message.content)

```

```typescript title="TypeScript" lines

const client = new OpenRouter({ apiKey: process.env.OPENROUTER_API_KEY });

  chatRequest: {
    model: "openai/gpt-4o",

    models: [
      "openai/gpt-4o",
      "anthropic/claude-sonnet-4.5",
      "openai/gpt-5-mini",
    ],
    messages: [{ role: "user", content: "Say hello in one short sentence." }],
  },
});

console.log("Model that answered:", res.model);
console.log(res.choices[0].message.content);

```

```go title="Go" lines
// The LiveKit plugin can't run here, so call OpenRouter directly with the same fallback configuration
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"log"
	"net/http"
	"os"
)

func main() {
	body, _ := json.Marshal(map[string]any{
		"model": "openai/gpt-4o",
		// Fallback models are tried in order if the primary model is unavailable
		"models": []string{
			"openai/gpt-4o",
			"anthropic/claude-sonnet-4.5",
			"openai/gpt-5-mini",
		},
		"messages": []map[string]string{
			{"role": "user", "content": "Say hello in one short sentence."},
		},
	})

	req, _ := http.NewRequest("POST", "https://openrouter.ai/api/v1/chat/completions", bytes.NewReader(body))
	req.Header.Set("Authorization", "Bearer "+os.Getenv("OPENROUTER_API_KEY"))
	req.Header.Set("Content-Type", "application/json")

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		log.Fatal(err)
	}
	defer resp.Body.Close()

	var res struct {
		Model   string `json:"model"`
		Choices []struct {
			Message struct {
				Content string `json:"content"`
			} `json:"message"`
		} `json:"choices"`
	}
	if err := json.NewDecoder(resp.Body).Decode(&res); err != nil {
		log.Fatal(err)
	}
	if len(res.Choices) == 0 {
		log.Fatalf("no choices returned (status %d)", resp.StatusCode)
	}

	fmt.Println("Model that answered:", res.Model)
	fmt.Println(res.Choices[0].Message.Content)
}

```

```bash title="cURL" lines
# The LiveKit plugin can't run here, so call OpenRouter directly with the same fallback configuration
# "model" is the primary; the "models" fallbacks are tried in order if the primary model is unavailable
res=$(curl -sS --fail-with-body https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-4o",
    "models": ["anthropic/claude-sonnet-4.5", "openai/gpt-5-mini"],
    "messages": [{"role": "user", "content": "Say hello in one short sentence."}]
  }')

echo "Model that answered: $(echo "$res" | jq -r '.model')"
echo "$res" | jq -r '.choices[0].message.content'

```

</CodeGroup>

```text title="Output"

Hello! How are you doing today?
```

#### Provider Routing

Control which providers are used for model inference:

<CodeGroup>

```python title="Python" lines
# The LiveKit plugin can't run here, so call OpenRouter directly with the same provider routing configuration

        model="deepseek/deepseek-chat-v3.1",
        provider={
            "order": ["deepinfra/fp4", "siliconflow/fp8", "coreweave/fp8"],
```

#### Analytics Integration

Include site and app information for OpenRouter analytics:

<CodeGroup>

```python title="Python" lines
from livekit.plugins import openai

llm = openai.LLM.with_openrouter(
    model="openrouter/auto",
    site_url="https://myapp.com",
    app_name="My Voice Agent",
)
```

```typescript title="TypeScript" lines
// The LiveKit plugin can't run here, so call OpenRouter directly with the same analytics configuration

const client = new OpenRouter({
  apiKey: process.env.OPENROUTER_API_KEY,

  appTitle: "My Voice Agent",
});

const res = await client.chat.send({
  chatRequest: {
    model: "openrouter/auto",
```
