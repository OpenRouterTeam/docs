## Mastra

Integrate OpenRouter with Mastra to access a variety of AI models through a unified interface. This guide provides complete examples from basic setup to advanced configurations.

### Step 1: Initialize a new Mastra project

The simplest way to start is using the automatic project creation:

```bash lines
# Create a new project using create-mastra
npx create-mastra@latest
```

You'll be guided through prompts to set up your project. For this example, select:

- Name your project: my-mastra-openrouter-app
- Components: Agents (recommended)
- For default provider, select OpenAI (recommended) - we'll configure OpenRouter manually later
- Optionally include example code

For detailed instructions on setting up a Mastra project manually or adding Mastra to an existing project, refer to the [official Mastra documentation](https://mastra.ai/en/docs/getting-started/installation).

### Step 2: Configure your environment variables

After creating your project with `create-mastra`, you'll find a `.env.development` file in your project root. Since we selected OpenAI during setup but will be using OpenRouter instead:

1. Open the `.env.development` file
2. Remove or comment out the `OPENAI_API_KEY` line
3. Add your OpenRouter API key:

```lines
# .env.development
# OPENAI_API_KEY=your-openai-key  # Comment out or remove this line
OPENROUTER_API_KEY=sk-or-your-api-key-here
```

You can also remove the `@ai-sdk/openai` package since we'll be using OpenRouter instead:

```bash lines
npm uninstall @ai-sdk/openai
```

### Step 3: Configure your agent to use OpenRouter

After setting up your Mastra project, you'll need to modify the agent files to use OpenRouter instead of the default OpenAI provider.

If you used `create-mastra`, you'll likely have a file at `src/mastra/agents/agent.ts` or similar. Replace its contents with:

<CodeGroup>

```typescript lines
import { Agent } from '@mastra/core/agent';
import { createOpenRouter } from '@openrouter/ai-sdk-provider';

// Initialize OpenRouter provider
const openrouter = createOpenRouter({
  apiKey: process.env.OPENROUTER_API_KEY,
});

// Create an agent
export const assistant = new Agent({
  model: openrouter('~anthropic/claude-opus-latest'),
  name: 'Assistant',
  instructions:
    'You are a helpful assistant with expertise in technology and science.',
});
```

```python title="Python" lines
import os
from openrouter import OpenRouter

# Initialize OpenRouter client
client = OpenRouter(api_key=os.environ["OPENROUTER_API_KEY"])

# Create an agent
instructions = "You are a helpful assistant with expertise in technology and science."

def assistant(prompt: str) -> str:
    res = client.chat.send(
        model="~anthropic/claude-opus-latest",
        messages=[
            {"role": "system", "content": instructions},
            {"role": "user", "content": prompt},
        ],
    )
    return res.choices[0].message.content

# Try the agent when you run this file directly
if __name__ == "__main__":
    print(assistant("What is quantum computing?"))

```

```go title="Go" lines
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"log"
	"net/http"
	"os"
)

func main() {
	// Create an agent: model + instructions
	body, _ := json.Marshal(map[string]any{
		"model": "~anthropic/claude-opus-latest",
		"messages": []map[string]string{
			{"role": "system", "content": "You are a helpful assistant with expertise in technology and science."},
			{"role": "user", "content": "What is quantum computing?"},
		},
	})

	req, _ := http.NewRequest("POST", "https://openrouter.ai/api/v1/chat/completions", bytes.NewReader(body))
	req.Header.Set("Authorization", "Bearer "+os.Getenv("OPENROUTER_API_KEY"))
	req.Header.Set("Content-Type", "application/json")

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		log.Fatal(err)
	}
	defer resp.Body.Close()

	var result struct {
		Choices []struct {
			Message struct {
				Content string `json:"content"`
			} `json:"message"`
		} `json:"choices"`
	}
	if err := json.NewDecoder(resp.Body).Decode(&result); err != nil {
		log.Fatal(err)
	}
	if len(result.Choices) == 0 {
		log.Fatalf("no choices returned (status %s)", resp.Status)
	}
	fmt.Println(result.Choices[0].Message.Content)
}

```

**Quantum computing** is a type of computation that uses the principles of quantum mechanics to process information in ways that classical computers cannot.

## The Basic Idea

**Classical computers** (like your laptop or phone) store information in **bits**, which are always either **0 or 1**.

**Quantum computers** use **quantum bits**, or **qubits**, which behave according to quantum physics.

## Key Quantum Principles

### 1. Superposition
A qubit can exist in a combination of 0 and 1 at the same time, with each outcome having a certain probability. When you measure it, it "collapses" to either 0 or 1. This lets a quantum computer represent many possible states at once: describing *n* qubits requires 2ⁿ numbers.

### 2. Entanglement
Qubits can become **entangled**, meaning their states are correlated so strongly that measuring one tells you something about the other, even at a distance. This creates correlations that have no classical equivalent.

### 3. Interference
Quantum algorithms are designed so that the probabilities of wrong answers cancel out and the probabilities of right answers reinforce each other. This is where the real computational power comes from.

## What Quantum Computers Might Be Good For

- **Cryptography**: Shor's algorithm could break widely used encryption (like RSA), which is driving the development of "post-quantum" cryptography.
- **Chemistry and materials science**: Simulating molecules for drug discovery, batteries, and catalysts.
- **Optimization**: Logistics, finance, and scheduling problems, though the size of any advantage here is still uncertain.
- **Searching**: Grover's algorithm speeds up unstructured search, but only quadratically.

## Common Misconceptions

- Quantum computers **don't simply try all answers at once**. Measurement gives you only one result, so algorithms must cleverly use interference.
- They **won't replace classical computers**. They're specialized tools for specific problems.
- They're **not faster at everything**. For most everyday tasks, classical computers are better.

## Current Challenges

- **Decoherence**: Qubits are extremely fragile and lose their quantum state when disturbed by heat, vibration, or electromagnetic noise.
- **Error rates**: Current qubits make frequent errors, so practical machines will need **quantum error correction**, which requires many physical qubits for each reliable "logical" qubit.
- **Scaling**: Building systems with millions of high-quality qubits remains a major engineering challenge.
- **Extreme conditions**: Many designs require cooling to near absolute zero.

### Basic Integration with Mastra

The simplest way to integrate OpenRouter with Mastra is by using the OpenRouter AI provider with Mastra's Agent system:

<CodeGroup>

```typescript expandable lines
import { Agent } from '@mastra/core/agent';
import { createOpenRouter } from '@openrouter/ai-sdk-provider';

// Initialize the OpenRouter provider
const openrouter = createOpenRouter({
  apiKey: process.env.OPENROUTER_API_KEY,
});

// Create an agent using OpenRouter
const assistant = new Agent({
  model: openrouter('~anthropic/claude-opus-latest'),
  name: 'Assistant',
  instructions: 'You are a helpful assistant.',

// Generate a response
const response = await assistant.generate([
  {
    role: 'user',
    content: 'Tell me about renewable energy sources.',
  },
]);

console.log(response.text);
```

### Advanced Configuration

For more control over your OpenRouter requests, you can pass additional configuration options:

<CodeGroup>

```typescript expandable lines
import { Agent } from '@mastra/core/agent';
import { createOpenRouter } from '@openrouter/ai-sdk-provider';

// Initialize with advanced options
const openrouter = createOpenRouter({
  apiKey: process.env.OPENROUTER_API_KEY,
  extraBody: {
    reasoning: {
      max_tokens: 10,
    },
  },
});

// Create an agent with model-specific options
const chefAgent = new Agent({
  model: openrouter('~anthropic/claude-sonnet-latest', {
    extraBody: {
      reasoning: {
        max_tokens: 10,
      },
    },
  }),
  name: 'Chef',
  instructions: 'You are a chef assistant specializing in French cuisine.',
});

// Generate a response
const response = await chefAgent.generate([
  {
    role: 'user',
    content: 'Suggest a classic French dish I can cook tonight.',
  },
]);

console.log(response.text);

```

```python title="Python" lines
import os
import requests

# Advanced options sent with every request
extra_body = {
    "reasoning": {
        "max_tokens": 10,
    },
}

# Create an agent with model-specific options
instructions = "You are a chef assistant specializing in French cuisine."

def chef_agent(messages: list[dict]) -> str:
    res = requests.post(
        "https://openrouter.ai/api/v1/chat/completions",
        headers={"Authorization": f"Bearer {os.environ['OPENROUTER_API_KEY']}"},
        json={
            "model": "~anthropic/claude-sonnet-latest",
            "messages": [{"role": "system", "content": instructions}, *messages],
            **extra_body,
        },
    )
    res.raise_for_status()
    return res.json()["choices"][0]["message"]["content"]

# Generate a response
response = chef_agent([
    {
        "role": "user",
        "content": "Suggest a classic French dish I can cook tonight.",
    },
])

print(response)

```

### Provider-Specific Options

You can also pass provider-specific options in your requests:

<CodeGroup>

```typescript lines
import { Agent } from '@mastra/core/agent';
import { createOpenRouter } from '@openrouter/ai-sdk-provider';

const openrouter = createOpenRouter({
  apiKey: process.env.OPENROUTER_API_KEY,
});

const chefAgent = new Agent({
  model: openrouter('~anthropic/claude-sonnet-latest'),
  name: 'Chef',
  instructions: 'You are a chef assistant specializing in keto cuisine.',
});

// Get a response with provider-specific options
const response = await chefAgent.generate([
  {
    role: 'system',
    content:
      'You are Chef Michel, a culinary expert specializing in ketogenic (keto) diet...',
    providerOptions: {
      // Provider-specific options - key can be 'anthropic' or 'openrouter'
      anthropic: {
        cacheControl: { type: 'ephemeral' },
      },
    },
  },
  {
    role: 'user',
    content: 'Can you suggest a keto breakfast?',
  },
]);

console.log(response.text);

```

import os
from openrouter import OpenRouter

client = OpenRouter(api_key=os.environ["OPENROUTER_API_KEY"])


# Create agents using different models
def make_agent(model, instructions):
    def generate(messages):
        res = client.chat.send(
            model=model,
            messages=[{"role": "system", "content": instructions}, *messages],
        )
        return res.choices[0].message.content
    return generate


claude_agent = make_agent("~anthropic/claude-opus-latest", "You are a helpful assistant powered by Claude.")

import (

// newAgent returns a function that chats with the given model and instructions
func newAgent(model, instructions string) func(prompt string) string {
	return func(prompt string) string {
		body, _ := json.Marshal(map[string]any{
			"model": model,
			"messages": []map[string]string{
				{"role": "system", "content": instructions},
				{"role": "user", "content": prompt},
			},
		})

		req, _ := http.NewRequest("POST", "https://openrouter.ai/api/v1/chat/completions", bytes.NewReader(body))
		req.Header.Set("Authorization", "Bearer "+os.Getenv("OPENROUTER_API_KEY"))
		req.Header.Set("Content-Type", "application/json")

		resp, err := http.DefaultClient.Do(req)
		if err != nil {
			log.Fatal(err)
		}
		defer resp.Body.Close()

		var result struct {
			Choices []struct {
				Message struct {
					Content string `json:"content"`
				} `json:"message"`
			} `json:"choices"`
		}
		if err := json.NewDecoder(resp.Body).Decode(&result); err != nil {
			log.Fatal(err)
		}
		if len(result.Choices) == 0 {
			log.Fatalf("no choices returned (status %s)", resp.Status)
		}
		return result.Choices[0].Message.Content
	}
}

# Quantum Mechanics, Simply Explained

Quantum mechanics is the set of rules that describes how **very tiny things** behave: atoms, electrons, and particles of light (photons). At that scale, nature works very differently from what we see in everyday life.

Here are the key ideas:

## 1. Things come in tiny chunks ("quanta")
Energy isn't smooth and continuous at the smallest scale. It comes in discrete packets. It's like a staircase rather than a ramp: an electron in an atom can sit on one step or another, but never in between. That's where the word "quantum" comes from.

## 2. Particles act like waves (and waves act like particles)
An electron can behave like a little ball in some experiments and like a spread-out wave in others. Light does the same thing. Neither "particle" nor "wave" fully captures what these things really are. They're something new that shows both behaviors.

## 3. Superposition: being in multiple states at once
Before you measure it, a quantum particle doesn't have one definite state. It exists in a combination of possibilities. An electron can be in a mix of "here" and "there." When you measure it, you get one definite answer.

*Analogy:* A spinning coin isn't quite heads or tails until it lands. (This analogy is imperfect, because the quantum version is stranger, but it gives the flavor.)

## 4. It's all about probability
Quantum mechanics usually can't tell you exactly what will happen, only the **odds** of each outcome. This isn't because our instruments are bad. It seems to be built into nature itself.

## 5. Uncertainty
You can't know certain pairs of properties perfectly at the same time, such as a particle's exact position and its exact momentum. The more precisely you pin down one, the fuzzier the other becomes. This is Heisenberg's Uncertainty Principle.

## 6. Entanglement: spooky connections
Two particles can become linked so that measuring one instantly tells you something about the other, even if they're far apart. Einstein called this "spooky action at a distance." (It can't be used to send messages faster than light, though.)

---

## Why it matters
Quantum mechanics might sound abstract, but it's behind much of modern technology:
- **Computer chips and transistors**
- **Lasers**
- **MRI machines**
- **LEDs and solar panels**
- **Quantum computers**, which are emerging now

## The bottom line
At the tiniest scales, the universe is **chunky, fuzzy, probabilistic, and interconnected** in ways that defy common sense. Yet quantum mechanics is one of the most precisely tested theories in all of science.

As physicist Richard Feynman said: *"If you think you understand quantum mechanics, you don't understand quantum mechanics."* So if it feels weird, you're getting it right!
