Português (Brasil)

- Address the user with você; verbs in the corresponding third-person form.
- Product terms follow terminology: guardrail (plural guardrails, masculine), predefinição (plural predefinições), and espaço de trabalho (plural espaços de trabalho) for Workspace. Never use barreira, grade de proteção, área de trabalho or ambiente de trabalho, never leave "Preset" in English, and never use the verb predefinir where the source has the noun: "Preset as Model" is "Predefinição como modelo".
- Sentence case for labels and headings. Nav labels are plural nouns where the English is plural: Guardrails, Predefinições. Buttons use the infinitive: Criar guardrail, Salvar alterações.
- Brazilian spelling and vocabulary (salvar, gerenciar, usuário), not European Portuguese (guardar, gerir, utilizador).
- Standard punctuation, no space before : ; ! ?
- "no longer" is "já não" placed directly before the verb (a conta já não possui), or "deixou de" / "deixa de". Do not split it into "não … mais" around the verb.
- Preferred product forms, use them in new translations even where existing copy still varies: créditos (Credits, never agradecimentos), provedor (never fornecedor or provider), limite de taxa (Rate limit), endpoint stays endpoint (never ponto de extremidade), chave de API (chave da API is tolerated in existing copy, never chave API), organização, atividade, registros (Logs, never logs), pesquisa na web, política de dados, taxa da plataforma (Platform fee, never tarifa or comissão), recarga automática (Auto top-up).
- Interns and Auto Router stay in Latin script: "Ori é um Intern", "criar Interns". Never estagiário or roteador automático. Zero Data Retention stays in English with ZDR, and the gloss form is "retenção zero de dados", never "zero retenção".
- Redact in guardrails is mascarar in every form: Mascarar (Redact), Mascarado (Redacted), regras de mascaramento (redaction rules). Never redigir or redação (those mean writing), censurar, remover, or ocultar for this action.
