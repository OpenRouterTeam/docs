Español (neutral, sin regionalismos)

- Usted forms for the user in prose. Buttons and labels use the infinitive or a noun phrase: Crear guardrail, Guardar cambios, Guardrails.
- Instructions inside prose, help text, and errors use the usted imperative (Visite, Elija, Termine, Inicie, Póngale), never the tú imperative (Visita, Elige, Termina, Inicia, Ponle).
- Product terms follow terminology: guardrail (plural guardrails, masculine), preajuste, and espacio de trabajo (plural espacios de trabajo) for Workspace. Never use barrera, guardarraíl, preestablecer, preconfigurar, área de trabajo or entorno de trabajo, and never turn a noun into a verb: "Preset as Model" is "Preajuste como modelo".
- Sentence case: capitalize only the first word of a label and proper names. Do not capitalize each word as English does.
- Spanish punctuation: opening ¿ and ¡ where a sentence asks or exclaims, no space before : ; ! ?
- Decimal numbers use the comma and a space before the percent sign: 99,9 %, not 99.9%.
- Avoid region-specific vocabulary (ordenador vs computadora); prefer the neutral term or the English loan the product already uses.
- Preferred product forms, use them in new translations even where existing copy still varies: créditos (Credits, never agradecimientos), proveedor (never provider), endpoint stays endpoint (punto de conexión is tolerated in existing copy, never punto final or extremo), clave de API (never clave API or llave), organización, actividad, registros (Logs), búsqueda web, política de datos, recarga automática (Auto top-up).
- Interns and Auto Router stay in Latin script. Never becario, pasante, or enrutador automático. Zero Data Retention stays in English with ZDR, and the gloss form is "retención cero de datos", never "cero retención".
- Redact in guardrails is enmascarar in every form: Enmascarar (Redact), Enmascarado (Redacted), reglas de enmascaramiento (redaction rules). Never redactar or redacción (those mean writing), censurar, or ocultar for this action.
