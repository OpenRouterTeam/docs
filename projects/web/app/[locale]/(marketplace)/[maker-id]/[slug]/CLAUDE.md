# AGENT GUIDELINES — model detail page

## Documentation section

The Documentation section on a model page (and the matching `softwareHelp` in its JSON-LD) is resolved by `model-documentation-resources.ts` from two sources: `model-documentation-map.gen.ts`, generated by `bun run generate:docs:model-map` from the `models:` frontmatter of pages in `projects/docs` (see `projects/docs/README.md`), and the hand-listed labs in the resolver itself. A family is `author/name-prefix`; a slug matches when the author matches and the model name equals the prefix or starts with `<prefix>-`, after `getStandardSlug` strips variants and the leading `~`. Never edit the generated file by hand.

Guides and cookbooks attach themselves through frontmatter in the docs PR. Labs are added to `LAB_ENTRIES` here. Link only pages that are live; the list is visible UI and mirrored into structured data, so a dead URL ships to users and crawlers. New families need resolver tests in `model-documentation-resources.test.ts` covering the versioned slug, the `~latest` alias, and a near-miss that must not match.
