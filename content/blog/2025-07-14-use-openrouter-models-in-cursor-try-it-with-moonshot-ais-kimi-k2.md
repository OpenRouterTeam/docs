If you're using [Cursor](https://cursor.com) as your AI coding assistant, you can now connect it to OpenRouter to access models like Kimi K2 by Moonshot AI, which is now live on the platform.

Kimi K2 delivers **1 trillion parameters**, a **65.8% SWE-Bench Verified score**, and leads the open-source charts for code generation and tool use. It is fully accessible in Cursor with just a few configuration steps.

## ⚙️ How to Use OpenRouter in Cursor

1. Open Cursor, go to:  
   `Settings → Cursor Settings → Models`

![Preview 1](https://openrouter.ai/cdn-cgi/imagedelivery/Xq3eUzdKO2-MoBklzEEuMQ/677c220c-da7a-4b83-04f6-4f4ef9c4e000/public)

2. Scroll down to **API Keys** and do the following:
   - Turn on **OpenAI API Key**
   - Paste in your **OpenRouter API key**
   - Enable **Override OpenAI Base URL**
   - Set it to: ```https://openrouter.ai/api/v1/cursor```

3. Scroll up to **"Add or search model"** and enter: **moonshotai/kimi-k2**
Add it, toggle it on, and you're set.

![Preview 2](https://openrouter.ai/cdn-cgi/imagedelivery/Xq3eUzdKO2-MoBklzEEuMQ/b1de0e29-a755-47dd-d52a-f5667c931900/public)

4. Now go to the chat pane in Cursor and choose **Kimi K2** from the model dropdown.

![Preview 4](https://openrouter.ai/cdn-cgi/imagedelivery/Xq3eUzdKO2-MoBklzEEuMQ/e524a81c-3345-4ff7-a0b1-e221d0a24200/public)

> ⚠️ Heads up: Cursor may warn that the model has limited agentic support. You can safely ignore this — Kimi K2 is fully capable in assistant-style workflows.
