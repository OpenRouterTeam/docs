# Vertex Gemini structured-output lowering fixtures

`gemini-2.5-flash-lite-structured-output-input.jsonl` holds caller batch lines, and
`gemini-2.5-flash-lite-structured-output-lowered.jsonl` the Vertex batch input line each one
lowers into. `gemini-2.5-flash-lite-structured-output-rejected-input.jsonl` holds the caller lines
that cannot be lowered without changing what the schema validates, each carrying the
`expected_error` the submit path must return.

The `envelope-only` line reproduces the schema shape that failed in production: Vertex job
`projects/582427911646/locations/europe-west4/batchPredictionJobs/7344918062170112000` (2026-08-21)
failed its import with `Invalid field name "$schema"`, so 0 of its 8 requests ran. The `local-refs`
line extends that shape to `$ref`/`$defs`, which reach the same import path. The `null-keywords`
line reproduces the next shape production rejected: job
`projects/582427911646/locations/europe-west4/batchPredictionJobs/3395023694454587392` (2026-08-27)
failed with `Only optional fields can be set to NULL. Field: enum; Value: NULL`, so the lowered
line must carry no null. The rejected lines
cover a reference out of the document (`external-ref`) and one whose pointer lands on a scalar
constraint rather than on a schema (`non-schema-target-ref`); both must fail with a 400 at submit
instead of reaching the input file.

The caller lines are synthetic; the lowered lines were generated by running the production
chat-completions skin and Vertex serializer over them, and are asserted line-for-line by
`vertex-gemini-structured-output-fixture.test.ts`. Whether the Vertex import accepts `$ref`/`$defs`
directly is untested — inlining removes the question rather than answering it.

The `web-search-tool` rejected line reproduces the tools shape that failed in production: a `web_search` tool lowered to `google_search: {}`, which the Vertex import rejects with `Cannot store struct 'request.tools.google_search' with no fields`. Captured live on 2026-09-21 through the OpenRouter Batch API on `google/gemini-3.8-flash-20260902` (job `batch-1789950922-avRYIKTItqUNuhY1pOiA`, 0 of 1 requests ran). The same request succeeded on the sync API. Production showed the same import failure on jobs `batch-1789721669-tbm6C65Uf09zaUYxmcl6` and `batch-1789721670-X5yCGAu2b38BgN8j3t64` (2026-09-18). The body is the live request with the model rewritten to the fixture's endpoint.
