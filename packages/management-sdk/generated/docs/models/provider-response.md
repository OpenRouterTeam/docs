# ProviderResponse

Details of a provider response for a generation attempt

## Example Usage

```typescript
import { ProviderResponse } from "@openrouter-monorepo/management-sdk-generated/models";

let value: ProviderResponse = {
  id: "chatcmpl-abc123",
  endpointId: "ep_abc123",
  modelPermaslug: "openai/gpt-4",
  providerName: "OpenAI",
  status: 200,
  latency: 1200,
  isByok: false,
};
```
