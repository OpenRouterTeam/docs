# Email Validation System

This directory contains a system for validating email addresses and detecting autogenerated or bot-created emails. The system analyzes both the username and domain parts of an email address to calculate a score indicating how likely the email is to be autogenerated.

## Overview

The email validation system:
1. Extracts features from the username part of the email
2. Extracts features from the domain part of the email
3. Combines these features using a logistic function to produce a final score
4. Classifies emails with scores above 0.65 as autogenerated/bot emails

## Username Features

The system extracts the following features from the username part of an email:

| Feature | Description | Range | Weight | Impact |
|---------|-------------|-------|--------|--------|
| length | Length of the username | ≥ 0 | 0.04 | Longer usernames are slightly more likely to be generated |
| entropy | Shannon entropy (randomness) of the username | 0-5 typically | 0.4 | Higher entropy suggests more randomness, more likely to be generated |
| digitRatio | Fraction of characters that are digits | 0-1 | 1.3 | Higher ratio of digits suggests generated content |
| symbolRatio | Fraction of characters that are symbols | 0-1 | 0.8 | Higher ratio of symbols suggests generated content |
| repeatRun | Length of longest repeating character sequence | ≥ 1 | 0.2 | More repeats suggest generated content |
| consonantVowelRatio | Ratio of vowels to consonants | 0-∞ | -1.2 | Closer to natural language ratios suggests human creation |
| commonWordsFrac | Fraction of username covered by common words | 0-1 | -2.0 | Higher usage of dictionary words suggests human creation |
| trigramPronounce | Pronounceability score based on English trigrams | 0-1 | -1.8 | More pronounceable usernames suggest human creation |
| longestAlternatingSequenceLength | Length of longest alternating letter-number sequence | ≥ 0 | 0.7 | Longer alternating sequences suggest generated content |

## Domain Features

The system evaluates domains based on:

| Feature | Description | Range | Weight | Impact                                                                                          |
|---------|-------------|-------|--------|-------------------------------------------------------------------------------------------------|
| domainSafetyScore | Score based on known trusted domains | 0 or 1 | 0.8 | Untrusted/sketchier domains (protonmail.com, hotmail.com, live.com) score 1.0, others score 0.0 |

## Scoring System

The final score is calculated using a logistic function:

```
score = 1 / (1 + Math.exp(-z))
```

Where:
- `z = BIAS + usernameFeaturesScore + domainFeaturesScore`
- `BIAS = -3` (biases toward human classification)
- `usernameFeaturesScore` is the weighted sum of username features
- `domainFeaturesScore` is the weighted sum of domain features

The resulting score ranges from 0 to 1:
- Scores closer to 0 indicate human-looking emails
- Scores closer to 1 indicate likely autogenerated emails
- Emails with scores above 0.65 are classified as autogenerated/bot emails

The system can also send alerts to Slack when autogenerated emails are detected.
